## 🇧🇷 Português

> **Buscador B2C de Voos com Alta Velocidade e Caching Integrado**

Engine de busca direta de passagens aéreas aberta ao consumidor final, integrada à cotação baseada em milhas e otimizada para performance.

### 🚀 Principais Funcionalidades
- **Busca Paralela de Alta Velocidade**: Varredura paralela de voos nos portais das companhias aéreas (GOL, LATAM, Azul).
- **Cache com Redis**: Armazenamento temporário de tarifas que reduz custos com consultas externas em 65%.
- **Conversão em Tempo Real**: Precificação automática traduzindo milhas em valores em R$ com base em regras comerciais.
- **Otimização de SEO**: Rotas e landing pages pré-renderizadas de destinos populares de voos.

### 🛠️ Tecnologias
- **Stack**: Next.js, Node.js, Express, Redis, PostgreSQL.
- **Infraestrutura**: Arquitetura orientada a microsserviços e filas de processamento assíncronas.

## 🇺🇸 English

> **B2C Flight Search Engine with Redis Caching**

B2C airline booking engine that converts companion seat queries into real-time tickets using a fast miles pricing conversion.

### 🚀 Key Features
- **High-Speed Concurrent Search**: Parallel search queries across airline operators (GOL, LATAM, Azul).
- **Redis Cache Layer**: Temporarily stores flight search results, saving 65% on external request costs.
- **Live Currency Conversion**: Converts airline miles costs to end-user ticket pricing instantly.
- **SEO Ready**: Dynamically pre-rendered routes for popular domestic flight destinations.

### 🛠️ Tech Stack
- **Stack**: Next.js, Node.js, Express, Redis, PostgreSQL.
- **Infrastructure**: Microservices, background worker queues.
